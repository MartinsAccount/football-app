# Backtest: piaci kombinálás (`w`) + EV-küszöb

> Generált fájl (`npm run backtest:blend -w @football/db`), kézzel ne szerkeszd. Terv: `docs/plans/model-v1.md` (I26b).

## Protokoll

- Adat: football-data.co.uk CSV, top 5 liga, 2022/23–2024/25 (0 élő hívás). **Hangolás csak a 2023/24-es validáción**; a
  2024/25-ös holdout zárolt, csak a végső táblázat nézi (egyszer).
- Modellek: v0 `elo-poisson@0.1.0` (fix paraméterek) és M2 `dixon-coles@1.0.0` (ξ = 0,002/nap, ridge = 4, I26 validáció),
  walk-forward. Az M1 kimarad: a β/c1/c2 2022–2023-on illesztett, a 2023-as validáció neki in-sample.
- Piaci valószínűség: a nyitó átlag-odds (`Avg*`) arányos marzs-levonással. Keverés: `logit` =
  `logit(p) = w·logit(p_m) + (1−w)·logit(p_piac)`, renormálva (az élő `evaluateMarket` ezt használja); `lineáris` =
  `w·p_m + (1−w)·p_piac`.
- `w` és módszer: a validációs 1X2 + O/U 2,5 log-loss összegének minimuma (rács w = 0; 0,1; …; 1). Küszöb: a 0% / 2% / 3% / 5% /
  8% / 10% / 15% közül a legnagyobb átlagos CLV, legalább 100 tippel (két piac együtt); döntetlennél a ROI. Tipp: flat 1 egység a
  Bet365 nyitón, CLV a Bet365 záróhoz, meccsenként és piaconként a legnagyobb EV-jű kimenet (a §5 többi szűrője – min. eltérés,
  odds-tartomány, irodaszám – itt nincs).
- Élő pipeline: változatlan (`blendWeight` = 0,25, `evThreshold` = 5%); az átállás 🔶 a tulajdonosé.

- `elo-poisson@0.1.0` (v0): **logit keverés, w = 0, EV-küszöb 0%**. A modell a validáción nem ad információt a nyitó piachoz (a
